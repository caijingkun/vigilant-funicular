## 三、详细操作步骤（从零开始）

### 方式一：一键启动（推荐，最简单）

#### 步骤0：环境准备

##### 0.1 检查 Python 是否已安装

**Windows**：按 `Win + R`，输入 `cmd` 打开命令提示符，输入：

```bash
python --version
```

**成功标志**：显示类似 `Python 3.10.x` 的版本号。

如果提示"不是内部或外部命令"，说明未安装 Python，请前往 [python.org](https://www.python.org/downloads/) 下载并安装 **3.8 以上版本**。安装时勾选 **"Add Python to PATH"**。

**macOS/Linux**：打开终端，输入：

```bash
python3 --version
```

#### 0.2 打开命令行 / 终端

- **Windows**：按 `Win + R` → 输入 `cmd` → 回车
- **macOS**：`Cmd + 空格` → 输入 `Terminal` → 回车
- **Linux**：`Ctrl + Alt + T`

#### 0.3 安装依赖库

在命令行中输入：

```bash
pip install -r requirements.txt
```

**成功标志**：最后出现 `Successfully installed pandas-xxx numpy-xxx ...` 字样。

如果已安装过部分库，会显示 `Requirement already satisfied`，属正常现象。

**验证安装成功**：

```bash
python -c "import pandas, numpy, sklearn, streamlit; print('依赖安装成功')"
```

成功标志：输出 `依赖安装成功`。

#### 0.4 一键启动系统

完成Python安装和依赖安装后，只需**双击** `启动系统.bat` 文件，或在命令行运行：

```bash
python run.py
```

系统会自动完成以下全部步骤：
1. ✅ 检查所有依赖库（缺少的自动安装）
2. ✅ 检查数据文件（不存在则自动生成）
3. ✅ 检查模型文件（不存在则自动训练）
4. ✅ 生成数据录入模板（首次运行）
5. ✅ 运行仿真实验（结果不存在时自动执行）
6. ✅ 启动Streamlit可视化界面

**无需手动执行后续步骤1-5**，一键启动会自动完成所有操作。

## 四、常见问题与解决方案

### Q1：pip install 安装失败怎么办？

**可能原因与解决方案**：

1. **网络问题**：使用国内镜像源加速

   ```bash
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```

2. **权限不足**：加 `--user` 参数

   ```bash
   pip install -r requirements.txt --user
   ```

3. **版本冲突**：升级 pip 后重试

   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. **streamlit 安装缓慢**：单独安装

   ```bash
   pip install streamlit -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```

### Q2：Streamlit 端口 8501 被占用怎么办？

**方法1**：指定其他端口启动

```bash
streamlit run src/app.py --server.port 8502
```

然后浏览器打开 `http://localhost:8502`

**方法2**：关闭占用 8501 端口的进程

```bash
# Windows 查看占用进程
netstat -ano | findstr :8501
# 终止进程（替换PID）
taskkill /PID <进程ID> /F
```

### Q3：运行报错怎么办？

| 报错信息 | 原因 | 解决方案 |
|---------|------|---------|
| `ModuleNotFoundError: No module named 'pandas'` | 依赖未安装 | 运行 `pip install -r requirements.txt` |
| `FileNotFoundError: ... classroom_energy_dataset.csv` | 未先运行数据生成 | 先执行步骤2：`python src/data_generation.py` |
| `ModuleNotFoundError: No module named 'decision_algorithm'` | 路径问题 | 确保在项目根目录运行，而非 src/ 目录内 |
| `UnicodeDecodeError` | 编码问题 | 确保使用 Python 3.8+ |
| `Font not found` 图表中文乱码 | 系统缺少中文字体 | Windows 通常自带 SimHei；Linux 需安装 `sudo apt install fonts-wqy-zenhei` |
| `ImportError: No module named 'PIL'` (verify_files.py) | 缺少 Pillow | `pip install Pillow` |

### Q4：如何重新运行整个流程？

## 五、各文件功能说明

### 5.1 `src/data_generation.py` — 仿真数据集生成

**主要功能**：生成桂林地区高校教室全年小时级（8784行）仿真数据集，模拟多源数据融合场景。

**输入**：内置物理参数（教室尺寸、空调参数、热学参数）和时间范围配置。

**输出**：
- `data/classroom_energy_dataset.csv`（传统模式）
- `data/classroom_energy_optimized.csv`（优化模式）

**关键函数**：
- `generate_weather(start, end)` — 生成桂林小时级气象数据（温度、湿度）
- `generate_schedule(dates)` — 生成课表特征（上课时段、人数、使用强度）
- `simulate_environment(weather_df, schedule_df, mode)` — 逐小时仿真室内温湿度、CO₂、空调能耗
- `main()` — 主函数，串联生成流程

---

### 5.2 `src/model_training.py` — AI时序预测模型训练

**主要功能**：训练空调能耗预测模型，首选LSTM（需PyTorch），未安装时自动回退RandomForest。

**输入**：`data/classroom_energy_dataset.csv`

**输出**：
- `models/` 目录下的模型文件（`rf_model.pkl` 或 `lstm_model.pth`）
- `results/prediction_vs_actual.png`（预测对比图）
- `results/model_metrics.txt`（精度指标）

**关键函数/类**：
- `load_and_preprocess()` — 加载数据并归一化
- `create_sequences(df_scaled, feature_cols, lookback)` — 创建时序序列样本
- `split_data(X, y)` — 按时间顺序划分训练/验证/测试集（7:1.5:1.5）
- `train_lstm(...)` / `train_rf(...)` — 训练LSTM或RandomForest模型
- `calculate_metrics(y_true, y_pred)` — 计算MAPE、RMSE、R²
- `LSTMModel`（类） — PyTorch LSTM网络定义

---

### 5.3 `src/decision_algorithm.py` — 双约束决策算法

**主要功能**：基于"最小能耗 + CO₂达标 + 温度舒适"双约束条件，输出空调控制策略（设定温度、是否开窗、通风时长）。

**输入**：AI预测能耗、当前CO₂浓度、室外温湿度、室内温度、人员数、是否上课。

**输出**：`DecisionResult` 对象（含建议设定温度、是否开窗、通风时长、决策依据、预计节能）。

**关键函数/类**：
- `EnergyDecisionMaker`（类） — 双约束智能节能决策器
- `make_decision(...)` — 根据环境参数生成单次决策
- `batch_decide(df)` — 对数据集批量生成决策
- `DecisionResult`（数据类） — 决策结果容器

**约束标准**：CO₂ ≤ 1000ppm（GB/T 18883-2022）、室内温度 24~28°C、碳排放系数 0.5 kg CO₂/kWh。

- `results/co2_timeseries.png` — CO₂时间序列对比
- `results/experiment_report.txt` — 文本实验报告
- `results/metrics_summary.csv` — 指标汇总
- `data/classroom_energy_ai_optimized.csv` — AI决策仿真数据

**关键函数**：
- `load_data()` — 加载传统与优化模式数据
- `simulate_ai_mode(df_opt)` — 叠加决策算法推荐列
- `calculate_metrics(df, label)` — 计算总能耗、CO₂超标率、碳排放等指标
- `plot_bar_comparison(...)` — 绘制柱状对比图
